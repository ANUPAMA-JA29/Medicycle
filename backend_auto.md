We will implement a complete, premium, and functional **Automation Workflow Module** for MediCycle AI. This module will model real-world automation systems (like Zapier or n8n) tailored for healthcare and pharmacy tracking. It includes a management interface, an automated logic engine (simulated APIs/services), database integration, and automation logging.

## Proposed Changes

### Database & Simulation Layer (API & Services)
We will create a service that mocks API endpoints and persists workflow states, logs, and sent emails under `localStorage`. 

#### [NEW] [automation.js](file:///home/abhinav/Desktop/Medicycle/src/services/automation.js)
This file houses our core workflow engine and API system.
- **Workflow Schema**:
  - `id`: Workflow ID (e.g., `wj-expiry`, `wj-donation`, `wj-add`)
  - `name`: Human readable title
  - `description`: Subtext explanation
  - `trigger`: Event triggers (e.g., `scheduler_daily`, `medicine_donated`, `medicine_added`)
  - `actionType`: `email` | `system` | `both`
  - `isActive`: Boolean toggle
- **Log Schema**:
  - `id`: Unique run ID
  - `timestamp`: ISO String
  - `workflowId`: Associated workflow
  - `details`: Text description of execution
  - `status`: `'success'` | `'skipped'` | `'failed'`
- **Sent Mail Schema**:
  - `id`: mail identifier
  - `timestamp`: ISO String
  - `recipient`: target user email
  - `subject`: mail subject
  - `body`: HTML/formatted text body
  - `type`: `'expiry'` | `'donation'`
- **Public API Methods**:
  - `getWorkflows()`: Returns workflows
  - `toggleWorkflow(id)`: Enables/disables a workflow
  - `getLogs()`: Returns execution logs
  - `clearLogs()`: Empties logs
  - `getSentEmails()`: Returns all simulated emails
  - `triggerExpiryCheck(medicines, userEmail)`: Manually or automatically runs the Expiry Cron check
  - `handleMedicineAdded(medicine, userEmail)`: Checks trigger condition and fires workflow
  - `handleMedicineDonated(medicine, userEmail)`: Checks trigger condition and fires workflow
  - `handleDonationCompleted(medicine, userEmail)`: Processes donation complete notifications
